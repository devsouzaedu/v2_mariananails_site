### 2. 🧠 Sistema de Quizzes

#### Quizzes aparecem após cada 5 aulas:

**Quiz 2 - Após Módulo Inicial Aula 05:**

**Quiz 3 - Após Módulo Inicial Aula 10:**
- **Pergunta:** Qual formato de unha é mais versátil e indicado para iniciantes?

- Alternativas: Stiletto / Formato extremo em ponta

**Quiz 4 - Após Módulo Inicial Aula 15:**
- **Pergunta:** O que é essencial ao fazer um banho de gel?
- **Resposta Correta:** Preparação adequada e aplicação em camadas finas

- **Pergunta:** Qual é a frequência ideal para manutenção de unhas alongadas?

- Alternativas: Somente quando as unhas caírem / A cada 2 meses

## 📊 Nova Estrutura do Banco de Dados

### Tabela `videos` (ATUALIZADA):
```sql
CREATE TABLE public.videos (
  id SERIAL PRIMARY KEY,
  titulo TEXT NOT NULL,
  descricao TEXT,
  youtube_id TEXT NOT NULL,
  ordem INTEGER NOT NULL,
  duracao INTEGER,
  pontos_ao_completar INTEGER DEFAULT 10,
  modulo TEXT DEFAULT 'Curso Principal',
  thumbnail_url TEXT,
  is_locked BOOLEAN DEFAULT false,      -- NOVO
  unlock_url TEXT,                      -- NOVO
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Tabela `quizzes` (NOVA):
```sql
CREATE TABLE public.quizzes (
  id SERIAL PRIMARY KEY,
  modulo TEXT NOT NULL,
  aula_numero INTEGER NOT NULL,
  pergunta TEXT NOT NULL,
  resposta_correta TEXT NOT NULL,
  resposta_2 TEXT NOT NULL,
  resposta_3 TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(modulo, aula_numero)
);
```

### Tabela `quiz_respostas` (NOVA):
```sql
CREATE TABLE public.quiz_respostas (
  id SERIAL PRIMARY KEY,
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE NOT NULL,
  quiz_id INTEGER REFERENCES quizzes(id) ON DELETE CASCADE NOT NULL,
  resposta_escolhida TEXT NOT NULL,
  correta BOOLEAN NOT NULL,
  respondido_em TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(user_id, quiz_id)
);
```

## 🚀 Como Implementar em Produção

### Passo 1: Backup do Banco Atual
```sql
-- Fazer backup das tabelas existentes
pg_dump -h seu_host -U seu_user -d seu_database > backup_plataforma_mariposas.sql
```

### Passo 2: Executar o Novo Schema

1. Acesse o Supabase Dashboard
2. Vá em **SQL Editor**
3. Execute o arquivo `supabase_schema_plataforma_mariposas_v2.sql`

**IMPORTANTE:** O script irá:
- ✅ Criar as novas colunas `is_locked` e `unlock_url` na tabela `videos`
- ✅ Criar as novas tabelas `quizzes` e `quiz_respostas`
- ✅ Inserir os 25 novos vídeos
- ✅ Inserir os 5 quizzes
- ✅ Atualizar badges (novo badge "Quiz Master")
- ✅ Criar políticas RLS apropriadas

### Passo 3: Deploy do Código

```bash
# Fazer commit das mudanças
git add .
git commit -m "feat: Plataforma Mariposas V2 - Quizzes e Aulas Travadas"

# Deploy (depende da sua plataforma)
vercel --prod  # ou
npm run deploy # ou
git push origin master  # se auto-deploy
```

### Passo 4: Verificar Funcionamento

1. ✅ Acessar `/plataforma/login`
2. ✅ Fazer login com uma conta
3. ✅ Verificar se os vídeos aparecem corretamente
4. ✅ Testar aulas travadas (deve mostrar cadeado)
5. ✅ Completar 5 aulas e verificar se quiz aparece
6. ✅ Responder quiz e verificar se salva no banco
7. ✅ Clicar no botão de compra nas aulas travadas

```sql
  'Resposta incorreta 1', 
  'Resposta incorreta 2'

```

### Travar/Destravar Aulas:
```sql
-- Travar aula
UPDATE public.videos 
SET is_locked = true, 
    unlock_url = 'https://pay.kiwify.com.br/lf9IZHj'
WHERE id = 10;

-- Destravar aula
UPDATE public.videos 
SET is_locked = false, 
    unlock_url = NULL
WHERE id = 10;
```

### Alterar URL de Desbloqueio:
```sql
UPDATE public.videos 
SET unlock_url = 'https://nova-url-kiwify.com.br/produto'
WHERE is_locked = true;
```
